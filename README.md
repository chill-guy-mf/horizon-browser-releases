# Horizon Browser

**The browser that does the work.** Ask anything and get the answer beside the page, or hand Horizon a task and watch it done in a tab. Ads, trackers, fingerprinting and cookie pop-ups are blocked by default.

→ **[horizon-ai-u8ey.onrender.com/browser](https://horizon-ai-u8ey.onrender.com/browser)**

## Download

**[Download Horizon Browser for Windows](https://github.com/chill-guy-mf/horizon-browser-releases/releases/latest/download/Horizon-Browser-Setup.exe)** (Windows 10 and 11, 64-bit)

Run the installer; Horizon opens when it's done and appears as **Horizon** in the Start menu.

> Windows may say **"Windows protected your PC"** because the installer isn't code-signed yet. Click **More info → Run anyway**. Each release lists its SHA-256 so you can check the file.

## What's in it

- **Horizon built in**: questions are answered in the side panel; tasks on a site ("open Gmail and tell me what needs a reply") run in a tab, in front of you or in the background. It asks before anything it can't undo, and never types passwords.
- **Private by default**: ad & tracker blocking (uBlock Origin's lists), fingerprint protection, cookie pop-up hiding, per-site permission prompts, a local encrypted password vault.
- **Everything else**: vertical tabs, sleeping tabs, Chrome Web Store extensions, import from Chrome, Edge, Brave and Firefox, a command bar (Ctrl K), crash-proof session restore.

This repository only hosts releases.
